# 《方块世界》原版体验优化任务

项目在 `E:\MinecraftOffline`，源码在 `app`，可玩成品是 `游戏\方块世界\方块世界.exe`。请直接在现有 Electron + Three.js 项目上实现体验改进。目标是让玩家从进世界到过完第一夜，就能感受到《我的世界》原版的画面、操作节奏和环境氛围。

以 **Minecraft Java Edition 1.21、默认资源包、无光影、键鼠、生存模式** 为本轮参照。先固定参照版本和场景。能运行原版就实测录制，对比同类地形、同样的昼夜和动作。使用原创或许可明确的贴图、模型、音频，保留中文、离线和 Windows 便携运行。开始前查看 Git 状态，保留现场的未提交修改和真实存档。沿用已有功能和存档结构，优先改首次游玩会频繁碰到的内容。扩展维度、大规模追加物品和结构留到后续。

## P0 · 先统一色彩和光照，再重画最常见的材质

- **已看到**。固定种子 `visual-audit-2026` 晴天的草和树叶偏黑，远景变成与天空脱节的蓝色剪影。水面密集重复亮点像铺砖，木板、圆石、玻璃和石砖的接缝过于抢眼，火把附近的材质仍偏灰暗。
- **已验证**。`gfx/atlas.js` 把图集标为 sRGB，`gfx/view.js` 的自定义体素着色器直接写入光照计算结果。同机位临时补上 `<colorspace_fragment>`，晴天草地和远景明显恢复层次。先以这组 A/B 为起点，核对天空、雾、实体与水的色彩空间，校准白天、夜间和火把的亮度及色温。夜里保有暗部，火把附近有清楚的暖色梯度。
- 再动 `gfx/painters.js`。先收敛草顶和草侧、泥土、石头、圆石、原木、木板、树叶、沙、水、玻璃、煤铁矿、工作台和熔炉。保留 16×16 像素尺度，用成簇的纹理和克制的对比区分材质。圆石减弱规则格子和黑缝，木板减弱深黑线，水弱化重复高亮，树叶从远处也有形体。连片和手持近景都要看，别用单块材质图验收。
- **验收**。在相同坐标、视角、视距、亮度、时间和天气下，出晴天林缘、水岸、材料排布、夜间、无火把/有火把的洞穴对照图。截图标注实际分辨率，逐张打开确认画面和标签一致。

## P0 · 让挖、放、打和移动符合准星与按键预期

- **已复现**。石剑在 32 ms 的模拟输入间隔内连续两次各扣 6 点，僵尸生命 `14 → 8 → 2`。准星已被 0.52 格外的石墙拦住，墙后僵尸仍从 `14 → 8`。当前 `world/mobs.js` 的 `pickNearest()` 用脚底加固定偏移和 0.85 格容差近似射线，`attackMelee()` 无遮挡判定，攻击复用了生存挖掘的 5 格距离。
- 在 `player/interaction.js`、`world/mobs.js` 用实际视点与目标碰撞盒确定最近命中，并和方块命中距离比较。按 Java 参照分开方块交互与实体攻击距离。加按武器区分的攻击恢复与低调的准星提示。空挥、过早挥击、满蓄力命中分别反馈，连点不能连续结算满额伤害。村民、剪羊毛等共用目标选择的入口要回归。现有红闪会把整个模型涂成亮红，换成短促且能看清皮肤的受击叠色，配合击退、音效与挥击。
- 挖掘已有裂纹、工具等级和碎屑。把挥手、触碰音、裂纹推进、破碎和掉落对齐到同一动作节奏。对准同类相邻方块，切目标或切工具时核对进度重置。放置仍要利落，草、木、石、沙的落块声可区分。验收覆盖手砍木、木镐挖石、铁镐挖矿、连续搭路和取消挖掘。
- **已复现**。`player/controller.js` 允许不按跳跃爬上完整一格，按住 Shift 也会走下平台。`player/input.js` 在 320 ms 窗口内收到重复 `keydown` 时可以误触双击 W。按原版手感校准完整方块、半砖/楼梯（如项目支持）、悬边潜行和按键重复。保留中文输入法环境下可用的双击 W，检查背包开关、鼠标重新锁定、切栏、创造飞行升降与准星响应。
- **验收**。实录正常按键和点击，覆盖墙前/墙后/墙边、不同距离、空挥/快点/等恢复、正面举盾/侧后方受伤、潜行边缘和普通走落。为遮挡、连点、潜行和按键重复补回归用例。

## P1 · 生物外形、光照和行为一起验收

- **已看到**。僵尸、骷髅、苦力怕、猪和羊大部分是纯色盒子。僵尸和骷髅共用醒目的红点眼，骷髅的胸口没有肋骨，弓远看像一根杆。夜间草地变暗，模型依旧很亮。`world/mobs.js` 以纯色 `MeshBasicMaterial` 为主，模型没有随着世界光照压暗。
- 先改苦力怕、僵尸、骷髅、蜘蛛、猪和羊。给各部件有辨识度的原创像素面贴图、轮廓和转轴。苦力怕要读出四只短脚、表情和身体斑纹，骷髅要读出眼窝、肋骨和弓臂，僵尸要能从配色和抬手姿势认出来。让生物采样当前位置的世界光照和雾，保留必要的眼部和引信提示。检查受击后恢复贴图和光照的表现。
- 骷髅先拉弓再放箭，让玩家来得及看懂并躲开。苦力怕靠近、嘶声预警、撤离取消与爆炸要有连贯节奏。僵尸的追击要尊重障碍物，蜘蛛要能辨认爬墙动作。先在同场地录白天、夜晚和火把边的剪影及动作，再看自然夜间遭遇。

## P1 · 先改音乐什么时候响，再改它听起来怎样

- **已验证**。实际编排离线导出三首 WAV，白天 24.6 秒、夜晚 31.0 秒、洞穴 32.0 秒，无削波。`audio/sfx.js` 会紧接着循环同一首，进洞或昼夜切换就切曲。离线样本的洞穴 RMS 比白天和夜晚高约 11 dB，游戏内混音仍需单独试听。关闭音乐目前也会停掉环境声床。Minecraft 官方对早期原版配乐的描述强调稀疏出现、缓入，以及音乐之间由游戏音效填充的长段留白。[官方配乐文章](https://www.minecraft.net/en-us/article/taking-inventory--music-disc)
- 保留独立的环境层。风、雨、滴水、夜间声和怪物预警在音乐空档仍可听见。让原创曲目低频率出场，曲终后有明显留白，避免路过洞口时频繁重启主曲。改成音符更稀疏、带自然余韵的原创钢琴或柔和合成音色。音乐音量为零时，保留环境层和动作音的独立控制。
- 优先打磨脚步、挖掘、破坏、放置、拾取、挥空、命中、举盾和引信。就近声音随方向和距离变化，同一材质有轻微变体。先确保挖放和危险提示在默认音量下清楚，再调配乐。
- **验收**。交付原始与改后同一路线的录音或带声短片。连续 5–10 分钟实际听一轮，包括静走、砍树、雨中、洞口来回、骷髅和苦力怕。检查留白、动态、声像及设置开关。把试听结论和 WAV 数值分开记录。

## P2 · 用第一夜校准生存节奏和 HUD

- 新档已是空背包，也有从原木到铁锭的六步提示。截图里窄窗口右下目标文字侵入第 9 格，背包的下一步建议占了大块空间。把这条线收进可随时打开的可选提示，压低常驻信息，先保证准星、生命、饥饿、快捷栏和合成好读。验收截图覆盖约 900×500 和 1280×720。
- `game.js` 默认整轮昼夜 600 秒，初始 `0.08` 到床逻辑判定入夜 `0.55` 约 4.7 分钟。实玩比较玩家准备木石工具、照明、食物和躲避的时间，再调节默认节奏。`mobs.js` 的自然刷怪从地表高度选点，敌对池受全局日照控制。优先补暗洞和点火把前后的真实风险差异，并检查安全出生区和已有敌怪生成预算。参照原版允许玩家在第一夜挖洞躲避、睡觉或主动迎战。[官方首夜指南](https://www.minecraft.net/en-us/article/how-survive-your-first-night-minecraft)
- 用空背包自然出生和真实输入跑一遍「砍树 → 合成木镐 → 挖石升级 → 做火把或找避难所 → 度过第一夜」。录下过程中的卡点和实际耗时。固定种子用来回归，再用另外两个种子抽查，兼顾老存档和创造模式。
