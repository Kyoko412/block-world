## 2. 已确认的音乐与混音问题

### 洞穴录音主要由常驻低频构成

现有六秒洞穴录音里，**99.86% 信号能量位于 120Hz 以下**，最强频率约 49.8Hz；动作与重进样本也约 99.9% 位于该频段。代码的洞穴环境床正是持续的 48Hz 正弦与 72Hz 三角波，第一路内部增益达 .6，经环境床和 master 后足以解释这组能量读数。

这证明持续低频占据了当前录音的大部分能量。听起来是否压迫、轰鸣或疲劳仍需试听；不能把能量比例当作主观响度或“音乐不好听”的结论。

我的设计建议：普通采矿用低电平空间空气、间歇滴水和有距离的细节；强低频用于明确危险事件或遗迹压力段，做有/无常驻低频的 A/B，再决定衰减、滤波与出现时机。不要靠把所有声源一起调大来改善。

### 曲目与场景的响度需要分开校准

本轮用 FFmpeg loudnorm 读取整曲的输入综合响度，未对原曲应用处理：

| 原曲 | 时长 | 输入综合响度 |
|---|---:|---:|
| Exploration Theme | 134.4s | -25.05 LUFS |
| Forest Whisper Theme | 164.6s | -29.80 LUFS |
| Ambient Horror Track 01 | 48.0s | -19.92 LUFS |

三首母带本身有明显差异，当前又叠加了各自 trim、场景总线、环境床与淡入。六秒实际场景样本约为白天 -29.43 LUFS、夜晚 -56.06 LUFS、洞穴 -22.04 LUFS；夜晚可能落在渐入或稀疏段，**不能据此将整首夜曲强行提到与洞穴一致**。

先选取每首开头、主体、弱段和结束各 30–60 秒，与独立环境声一起校准，再做地表—夜晚—洞穴的连续转换试听。保留乐曲的自然动态与留白。当前数据不足以对旋律、编曲美感或三首曲目的最终去留打分。

## 3. 已确认的音效与触发问题

1. **既有“动作录音”没有覆盖它声称的内容。** `render-mix.mjs` 与 `render-mix-final.mjs` 在 capture 中先执行 setup，再等 400ms 才开始 MediaRecorder；6-actions 的挖、放、挥空、命中与受伤已经先执行完了。前两组还调用 T.setBlock，绕过正常挖掘/放置的音效出口。应先开始录制，再执行真实交互；现有 6-actions 不能作为挖放音效通过的证据。7/8 两段守卫音效已用延时触发，不能把这一问题扩大为所有录音均无效。
2. **声音身份复用过多。** 跳跃调用 click，工具损坏调用 hurt；守卫前摇复用苦力怕的 hiss，横扫/光弹复用 explode/bow，奖励同时叠 levelup 与 guardian_reward。它们会削弱事件辨识，需要按游戏语义重新分工，而不是每加一个功能就借用已有声音。
3. **放置缺少材质区分。** 当前常见放置出口都调用同一个 place，主要变化是 rate；木、石、土、玻璃等应有不同的接触与尾音特征。
4. **变体主要依靠音高随机。** 多数声源来自同一噪声/振荡器配方。脚步和挖掘需要少量不同瞬态/颗粒结构的变体，避免同一个声音机械重复；已有的轻微随机音高可以保留。
5. **世界声源方位表达不足。** Sfx.play 支持可选 pan，但本轮检查的多处生物/守卫调用没有传位置或 pan。应统一距离衰减与左右定位，让玩家能凭声音判断敌人的方向；UI 和自身反馈保持稳定位置。
6. **“播放背景音乐”开关同时关闭环境床。** 音乐音量拉到零时环境床仍保留，但关闭背景音乐开关会使风、虫鸣等一起停止。应将音乐与环境声的控制语义分开，暂停时再按暂停规则释放。

本轮独立导出的 31 种音效均成功播放，未出现数字削波。这只证明声音生成正常，不能证明材质感、辨识度、空间感或主观听感合格。

## 4. 我的声音设计方向

整体采用“自然材质与身体反馈，少量简洁旋律提示”。像素画面可以配细腻的材质声音；常规动作不必全变成电子滑音。

| 类别 | 目标特征 |
|---|---|
| 草、土、沙脚步 | 轻、短、有不同颗粒与摩擦结构；不抢音乐 |
| 石与木挖掘 | 石有干脆裂纹和碎屑；木有纤维、敲击与断裂，破坏声比连续敲击更完整 |
| 放置 | 木的闷接触、石的短硬撞、土的松散落定，避免所有方块一种“咚” |
| 挥空与命中 | 空挥轻气流；命中有明确接触与重量；受伤、工具坏和盾碎独立辨识 |
| 怪物 | 有种类身份、方向和距离；危险前摇不与普通动物或其他敌怪共用同一提示 |
| 守卫 | 与石/金属外形匹配的沉重运动、蓄能与冲击；让招式声与视觉预警同步 |
| UI/拾取/成就 | 短、轻、克制；高频提示不反复播放完整升级旋律，奖励层次清楚 |
| 音乐与环境 | 探索旋律有留白；环境提供空间；危险声优先，必要时短暂压低音乐 |

这是一套拟采用的设计标准，尚不能宣称当前样本已经满足它。新素材按作者原始来源与许可登记，挑选和处理以实际游戏对照为准，不以下载数量作为成果。

## 5. 建议执行顺序与验收

1. 修录音时序，分开录音乐、环境、音效及最终总混音；记录真实事件时点。
2. 先处理洞穴常驻低频、场景转换、音乐/环境开关，做不削弱危险反馈的 A/B。
3. 优先完善木/石/土挖放和脚步，再做战斗与怪物；每类准备少量变体，统一音量与材质特征。
4. 给世界声源补方向与距离；清理 click/hurt/hiss 等跨事件滥用和奖励叠音。
5. 在默认设置下连续录制地表操作、夜间避险、洞穴采矿、守卫战与暂停重进。试听检查材质能否辨认、危险能否定位、重复是否疲劳、音乐是否抢操作；机器检查负责无失声、无削波和生命周期。
