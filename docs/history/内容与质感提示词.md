## 3. 先写三份设计稿（T0，时间盒 45 分钟）

在 `docs/` 下新建（没有就建目录）：
- `content-audit.md`：生物/物品/配方/贴图/音效/音乐的清单与数量；标出**孤儿物品**
  （没有来源或没有用途，例如当前的火药）；列出「玩家最常看到的 20 个方块/物品」
- `art-direction.md`：调色板、光照方向、轮廓规则、UI 风格、粒子规则、Do/Don't
- `music-brief.md`：3 首曲子的调式/速度/乐器/段落/循环长度/切换规则

这三份是后面所有任务的验收依据。**写不出来说明还没想清楚，先别写代码。**

### 美术方向（写进 art-direction.md 的硬规则，可直接抄）
- 全部 16×16 像素画；每张 6~10 色，**不许大面积纯黑 #000 / 纯白 #fff**
- 光源固定在左上：亮部偏暖、暗部偏冷（阴影往蓝紫偏），边缘 1px 明暗过渡
- 每张至少 3 级明度；噪点/抖动不超过 20%，避免「电视雪花」
- 同类方块共享材质语言（木头有年轮、石头有裂纹、金属有高光），但不同方块轮廓必须可区分
- 物品图标在 16×16 下能只看轮廓认出来；同类工具有统一的柄色/材质色
- UI：4px 网格、暗底 + 暖色强调、圆角 6~8px、中文用微软雅黑/思源黑体；禁止浏览器默认按钮
- 生物：剪影优先，不许只换颜色；每种至少 2~3 个可动部件（腿/耳/尾/翼）

### 音乐方向（写进 music-brief.md，可直接抄）
- 白天：C 大调/A 小调五声，72~84 BPM，8 小节 loop；拨弦 + 柔和 pad + 轻低音
- 夜晚：A 小调，58~66 BPM，音乐盒/钟琴 + 低音 pad；稀疏、留白
- 洞穴/水下：D 小调 drone，无固定节拍；低频 pad + 滤波噪声 + 偶发滴水
- 每首至少 2 个声部（旋律 + 和声/低音）；**主题动机在 8 小节内重复 2 次**，不是随机音符
- 无缝循环；切歌 2~4 秒交叉淡入淡出；**任何时刻只有 1 首主曲 + 1 层环境床**
- 环境床：风、鸟（白天）、虫鸣（夜晚）、洞穴滴水、雨、雷；按群系/高度/天气切换
- 音效随机 detune ±5%、音量 ±8%，避免同一声反复像机枪

## 5. 每个任务的完成定义（DoD）

**机制类任务（生物/物品/成就）**：
1. 先红后绿（新增断言先在旧代码上红，红色原文贴进进度文件）

4. 提交 + 文档同步（内容清单/验收报告/进度）

**美术/音频类任务**：
1. **before/after 证据**：至少 1 张截图或 1 段 WAV 放 `artifacts/`
2. 结构/数值证据：调色板色数、帧率、音频峰值/循环接缝/活跃轨数
3. 不破坏既有断言与性能；提交 + 文档同步

**通用**：
- 一次只做一个任务；时间盒 40~60 分钟；做不完就交最小可用版本，剩余写回队列
- 绿灯即提交，允许 `wip:` 前缀；未提交窗口 < 15 分钟

## 为什么这样写（给自己看）

| 设计 | 针对的真实问题 |
|---|---|
| 先写三份设计稿再写代码 | 美术/音乐最容易「凭感觉改一通」，没有方向就会反复推翻 |
| 美术规则写成可检查的条目（色数/光源/纯黑纯白/轮廓） | 「好看」不可验收，但这些可以 |
| 音乐要求 3 首 + 动机重复 + 无缝循环 + WAV 证据 | 现在是随机五声音阶，没有曲式；WAV 让人能直接判断 |
| 音乐/环境床分轨、active ≤1 | 最容易出的 bug 是切天气时叠出两份循环 |
| 生物按「角色」设计（史莱姆=弹跳/粘液块，狼=伙伴，鱿鱼=染料） | 只加换色怪不算内容；每个新生物要带一个新玩法/新材料 |
| 物品矩阵强制「来源 + 用途」 | 现有火药就是孤儿；不加用途的物品只是数字 |
| 前 10 分钟脚本 + 成就 | 「不好玩」通常不是内容少，是前 10 分钟没有目标 |
| 美术/音频任务不要求先红后绿，但要 before/after + 数值证据 | 审美类不能套单测，但必须有证据 |
| 保留四条命令/绿灯提交/时间盒 | 这些在前几轮被证明有效，不要丢 |
