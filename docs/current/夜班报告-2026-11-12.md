## 3. 怎么玩（现在就能试）

1. 双击 `游戏\方块世界-Luanti\一键启动.cmd`
2. 主菜单应显示「方 块 世 界」与「单人游戏 / 选项 / 帮助 / 退出游戏」
3. 进入世界 `mcsound`（已启用三个 mod）
4. 想立刻看到蜜蜂：在游戏里输入 `/bee`（需要 `enable_server` 或单机权限；单机默认可用）

**你会听到**：脚步/挖掘/破坏/放置是我们的声音；进世界 14—28 秒后开始放洞穴曲（出生点在地下时）；
按 `F3` 可看帧率。

## 4. 今晚真实踩到的坑（都已修复）

1. **`minetest.sound_play(..., true)` 返回 nil**：`ephemeral` 参数让句柄恒为 nil，我原来的"播放中"判断失效，
   导致同一秒内重启了 3025 次配乐。改成不看句柄、只按时间记账，并把场景切换改成"等当前曲终"。
2. **洞穴判定过宽**：`y<24` 就当中洞穴，出生点在地下会直接放洞穴曲；补了光照条件 `<8`。
3. **`mcl_mobs.spawn` 已弃用**：改用 `core.add_entity`，`/bee` 与测试脚本同步。
4. **无玩家时生物会 despawn**：这是预期行为，不是 bug；所以"蜜蜂活着"只能在实机验证。

## 5. 已知问题（按严重度）

1. **没法目视验证**：我无法截屏/听声，菜单排版、HUD、音色、帧率都需要你早上确认。
2. **战斗/进食音效还没接**：现在打怪、吃东西仍是 Mineclonia 原声。
3. **配乐场景切换不即时**：正在播的曲子会放完（最长 96 秒），下一条才换场景。
4. **上游贴图缺失**：日志里有 `mcl_poplar_poplar_shelf.png` 加载失败（Mineclonia 自己的资源缺项，不影响运行）。
5. **蜜蜂是原型**：cube 模型 + 16×16 条纹贴图；行为只有"飞 + 躲 + 掉落蜜脾"，没有采蜜/授粉。
