## 二、决定只有三个门（按顺序，任何一门不过就停）

### G1 许可门（先决，必须你拍板）

- 引擎 **LGPL-2.1+**、Mineclonia 代码 **GPLv3**、材质 **CC BY-SA 4.0**。
- 含义：**一旦对外分发这套东西，"闭源 + 只发二进制"就不可能了**；我们写的 mod 也要以 GPLv3 提供源码。
- 我们的音频是 CC0，可以并入，不构成阻碍。

> **默认建议：按"开源发布"处理（G1 = 通过）。** 这套生态本来就是为此设计的；自用或开源发布完全没问题。
> 只有一种情况要停：你打算把它做成闭源商业产品。那就不要迁移，回自研（路线 C）。

### G2 身份门（决定"值不值得"）

Mineclonia 的材质是 Pixel Perfection（16px），音效是另一套。我们的优势是**声音设计**和中文表达。

- 验收方式：同一场景盲听 A/B（原版 Mineclonia vs 套了我们 mc_soundpack 的版本），以及并排截图。
- 通过标准：能听出"这是我们的游戏"，而不是"一个换了音效的 Mineclonia"。
- 若不通过：要么补一套自绘材质包（+2—4 周），要么承认这条路只是"内容扩容"，不是"我们的游戏"。

### G3 工程门（决定"能不能用"）

- 1080p、均衡档光影（动态阴影 + 后处理 + bloom）实测 **≥55 FPS**；中低配能切性能档。
- 中文无方块字、术语统一（"泥土/土块"这类）、键位改成 MC 习惯（E 背包、Ctrl 疾跑）。
- 存档/世界创建/退出不崩。

## 三、推荐路线：B（发行版 + 我们的声音与玩法 mod）

不是"用 Mineclonia 替换我们"，而是：

```
Luanti 引擎（LGPL）
└─ Mineclonia（GPLv3，内容与玩法，不改它一行源码）
   ├─ mods/mc_soundpack        ← 我们的五包音频（今天已完成移动/挖放）
   ├─ mods/mc_hud_zh           ← 中文术语润色、键位、HUD 微调
   ├─ mods/mc_look             ← 光影/材质档位（配置为主）
   └─ mods/mc_identity         ← 守卫 Boss / 任务 / 地标（我们的玩法，逐项移植）
```

关键纪律：**不 fork Mineclonia**，一切通过 mod 与 `minetest.conf` 实现——否则上游一升级就是地狱。

## 六、今天已经落地的代码（不是纸面计划）

- `.tools/ogg-pack.mjs`：WAV → 单声道 OGG 声音组（`<name>.ogg/.0/.1/.2`），一条命令重建。
- `游戏/方块世界-Luanti/mods/mc_soundpack/`：80 个 OGG + `init.lua`（按 footstep/dig/dug/place **分键位**重映射，避免 Mineclonia 复用组名导致破坏声变脚步声）+ `mod.conf`。
- 实测日志：`[mc_soundpack] 已重映射 2776 个节点、共 10861 个声音键位`，无 Lua 错误。
- `游戏/方块世界-Luanti/worlds/mcsound/`：启用该 mod 的测试世界，可直接进游戏听。
