## 2. 每段的验收标准（写进报告的就是这些）

### H1 中文界面
- 主菜单显示"方块世界"、单人游戏/选项/退出为中文。
- 进世界后 HUD 中文、无方块字。
- `minetest.conf`：`language=zh_CN`、`SYSTEM_SCANCODE_*` 键位（E 背包 / Ctrl 疾跑 / Q 丢弃）。
- 日志无 Lua 报错。

### H2 声音全量
- `mc_soundpack` 覆盖：脚步、挖掘、破坏、放置、受伤、摔落、跳跃、战斗命中、进食。
- `mc_music`：三首曲目按 场景（白天/夜晚/洞穴）切换，首次留白 14—28s，曲间留白 110—190s。
- 提示音 8 条可被触发（至少 craft/pickup/levelup 三条）。
- 证据：mod 加载日志 + 声音组文件清单 + 采样说明。

### H4—H6 生物（每个都要满足）
- `/spawnentity <name>` 能生成，能自然生成在对应群系。
- 有 idle / hurt / death 三条音效（我们自产，OGG）。
- 有掉落且能进现有合成（蜜脾/鳞甲/皮革等）。
- 中文名 + 图鉴条目。
- 同屏 20 只不崩、不卡死。

### H7 手感
- 命中生物、被击中、格挡、进食都有我们的音色。
- 报告里列出"哪些接上了、哪些只能下一轮"。

### H8 性能
- 1080p 均衡档：平均 FPS + p1（最低 1%）；流畅档一组对照。
- 记录采样方法与场景（固定航线）。
