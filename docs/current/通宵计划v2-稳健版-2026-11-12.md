# 通宵计划 v2（稳健版）：慢下来，只做能证明的事

> 上一版的问题不是做错，是**做得太快、把"脚手架"写成了"完成"**：
> 菜单只验证了"脚本加载"，没看排版；配乐只验证了"播了一次"，没验提示音；
> 生物只验证了"能生成"，没验行为。这次改成：**没有证据就不许写完成。**

---

## 0. 三条新规矩（这次的核心）

1. **完成的定义 = 证据三件套**
   - 一份可复现的命令或脚本；
   - 一份输出证据（日志片段 / 截图 / 数据表 / 哈希）；
   - 一句"已知限制"（它现在还不能做什么）。
   缺一条 → 在报告里只能写「部分」或「未做」。

2. **一晚最多推进 2 个"证据包"**
   一个证据包 = 一项功能 + 它的验证 + 一次提交。做完一个再开下一个，不并行铺开。

3. **能自证的先做，不能自证的排队等你**
   我能自证：文件完整性、注册表、headless 启动、声音组是否被请求、帧率采样、哈希。
   我不能自证：**排版好不好看、音色好不好听、手感爽不爽**——这些一律留给你回来。

## 5. 止损与回滚

- 任一证据包超过预计 50%：**砍到最小可证明版本**，写清限制，进下一个。
- 工程底座（A）如果做不完，**后面全部不做**——因为其余证据都依赖它的可复现性。
- 每次提交前跑一遍 `smoke.ps1`；红的不提交。
