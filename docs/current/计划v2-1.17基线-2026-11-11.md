# 计划 v2：以 1.17 为基线的方块世界（2026-11-11，讨论稿）

> 基线已定：**Minecraft 1.17（洞穴与山崖）为止**。Luanti 5.18.0 + Mineclonia 0.124.1 当骨架，我们做体验层与少量补齐。
> 本文只定范围、批次与验收，不含执行。

## 0. 三条硬边界

1. **内容基线 1.17**：1.19+ 的生物与方块一律不做（青蛙、悦灵、监守者、骆驼、犰狳、嗅探兽、清风人、嘶鸣兽、焦尸）。
2. **红石不做**：Mineclonia 已有 193 个红石节点，够基础使用；我们不投入补全与修 bug。
3. **不 fork 上游**：只做 mod、配置、覆盖映射；上游版本 pin 死，不追新。

## 1. 现状（实测，不是估计）

| 项 | 数字 |

**结论：内容不是瓶颈，体验才是。**

## 2. 批次制（每批 = 一个可玩包 + 一次试玩）

### Batch 0 打底（3—4 天）

| 事项 | 产出 |
| --- | --- |
| 中文菜单 + HUD + 1080p 配置 | 借鉴 Block World CN 的 `menu.lua`/HUD 包，改 5.18 键位（E/Q/Ctrl） |
| 音频全量接入 | `mc_soundpack`（移动+挖放）→ 扩到全量；`mc_music` 三首 + 八提示音，含场景切换与留白 |
| 打包骨架 | `一键启动.cmd`、世界 ZIP 备份、`NOTICE`/`licenses`、`KNOWN_GAPS`、版本号 |
| 性能基线 | 1080p 三档实测（均衡/流畅/高画质），定默认 |

**验收**：连续玩 30 分钟不难受；1080p 平均 ≥55、p1 ≥45；盲听能认出我们的脚步/挖掘/配乐。

### Batch 1—3 生物补齐（每个 2—3 天）

按"补现有系统"的顺序，每个生物一个可玩包：

| 批次 | 生物 | 补的是什么 | 必须交付 |
| --- | --- | --- | --- |
| 1 | **蜜蜂** | 蜂巢/蜂箱节点已存在（12 个），里面没蜂 | 实体 + 采蜜/授粉 + 被蜇 + 3 条音效 + 中文名 |
| 2 | **海龟** | 水生唯一缺口；`turtle_egg`/`scute` 为 0 | 实体 + 海滩产卵 + 幼龟入海 + 鳞甲→头盔 + 音频 |
| 3 | **狐狸** | 针叶林/雪原已有 | 实体 + 叼物/昼伏夜出 + 雪狐变种 + 音频 |

**验收（每个）**：能在对应群系自然遇到；有 idle/hurt/death 三条音效；掉落能进现有合成；中文名与图鉴无英文。

### Batch 4—5 生物补齐（每个 2—3 天）

| 批次 | 生物 | 说明 |
| --- | --- | --- |
| 4 | **山羊** | 山地专属 + 顶撞 + 山羊角（吹响） |
| 5 | **熊猫** | 丛林氛围 + 幼崽；玩法回报低，但"世界活着"的重要拼图 |
| 5b | **幻翼**（可选） | 失眠机制；建议默认低频，或做成世界选项 |

**验收**：经典 1.17 生物 100%，图鉴无空项；熊猫/山羊不破坏性能（同屏 30 只测一次）。

### Batch 6 手感（2—3 天）

- 战斗/进食音效移植（含"咬—嚼—吞"过程重写）
- 命中反馈：30—60ms 停顿、破坏碎屑、受击屏幕反馈
- 新 6 种生物的叫声（每只 3 条，自产）

**验收**：盲听 4/5；近战/远程/自爆三种敌人应对明显不同；进食被打断不扣物品。

### Batch 7 世界感（5—6 天）

- 地标（废墟/哨塔/前哨）移植：发现音效 + 地图标记 + 可搜刮
- 营地：夜晚篝火、可搜刮、专属音景
- 环境声分区（林地/洞穴/水下/雨）+ 配乐场景切换

**验收**：随机走访三处地点，能讲出三句不同的"这里发生过什么"。

### Batch 8 目的性（6—8 天）

- 轻任务线（5—7 节点，可跳过、不阻断）
- 守卫 Boss（四座封印 + 唤醒预警 + 战利品 + 失败重试）
- 成就/图鉴补全

**验收**：玩家能说出"下一步去哪"；Boss 有准备—交战—结算三段；失败可重试。

### Batch 9 发布收尾（2—3 天）

- 性能矩阵（1080p 三档 + 集显档）、存档兼容、崩溃日志
- 文档：`KNOWN_GAPS`、操作说明、许可清单、来源与修改声明
- 发布包 + 源码包 + SHA256 校验值

## 3. 依赖与顺序

```
Batch 0 ──┬─> Batch 1 ─> 2 ─> 3 ─> 4 ─> 5 ─┐
          ├─> Batch 6（可与 1—5 并行）      ├─> Batch 8 ─> 9
          └─> Batch 7（依赖 0 的音频）      ┘
```

- 生物批次之间无强依赖，但**每批都要单独打包**，避免一次改太多。
- Batch 6 的"新生物叫声"依赖对应生物先落地，可以放在 3/5 之后补。

## 4. 每批的固定动作（不许省）

1. 写代码 / 做素材。
2. 自动检查：mod 加载无错误、资源存在、注册表一致。
3. headless 冒烟：服务器能起、世界能进、实体能生成。
4. 打一个可玩包（保留玩家存档）。
5. 你试玩 20—30 分钟，回三件事：**哪里别扭、哪里无聊、哪里惊喜**。
6. 按反馈修，不新增范围；修完进下一批。

## 5. 明确不做

1.19+ 内容、红石补全、多人、服务器、16 色装饰、手机端、完整下界/末地通关、追 wiki 清单。
**1.17 生物补齐即内容封顶**，之后只做体验，不再加内容。

## 6. 止损点

- **Batch 0 不过**（帧率/中文/键位有硬伤）→ 先修，不进内容。
- **Batch 3 后**：如果三个生物没能让世界"活起来"→ 停下来重新想，不要继续堆第 4、5 个。
- **Batch 8 后**：如果任务线/Boss 让你觉得"多余"→ 砍掉，力气移到世界感与手感。
