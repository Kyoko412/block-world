## 二、每个证据包的"完成定义"模板

```
证据包 X：
  1. 做了什么（一句话）
  2. 复现命令（≤3 行）
  3. 输出证据（日志片段 / PNG / 数据表 / 哈希）
  4. 已知限制（它现在还不能做什么）
```
四行缺任何一行 → 只能写「部分」或「未做」。

## 六、视觉的边界（写进所有报告，不许含糊）

**Luanti 能做**：动态阴影、软阴影、色调映射、自动曝光、泛光、雾、粗体积光、水面反射、波动水面/树叶/植物、顶点级 AO、FXAA。
**Luanti 做不到**：逐像素光照、SSAO、PBR/法线、屏幕空间反射、真实 god rays、光追。

所以"光影"的目标是**把现有管线调到最好看**，不是对标 SEUS/BSL。
