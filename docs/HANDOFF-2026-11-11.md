## 一、项目是什么

- **新版**：Luanti 5.18.0 引擎 + Mineclonia 0.124.1 游戏（内容全由上游提供），
  我们只做**体验层**：中文、声音、光影、生物补全、世界感、目的性。

## 二、怎么跑（三行）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File luanti/scripts/fetch-deps.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File luanti/scripts/setup.ps1 -Target "E:\MinecraftOffline\游戏\方块世界-Luanti"

```

冒烟应输出：`冒烟通过：nodes=3060 items=3696 entities=291 bee=true 退出码=0`

启动：双击根目录 `启动游戏.bat`（新版）或 `启动经典版.bat`（经典版）。
新版进世界选 `mcsound`（已启用音效包/配乐/蜜蜂）。

## 五、规则（违反会被要求重做）

1. **完成 = 证据三件套**：可复现命令 + 输出证据 + 已知限制。缺一条只能写「部分/未做」。
2. **一次只推进 2—3 个证据包**，做完一个立刻提交，不并行铺开。
3. **不 fork Mineclonia**：只做 mod、`minetest.conf`、HUD 材质包；需要覆盖上游文件时写进
   `luanti/overrides.json` 并在 `NOTICE.md` 说明。
4. **不动玩家存档**、不动经典版（`app/`）与 `游戏/方块世界/`。
5. **不提交** `游戏/`、`artifacts/`、`downloads/`、`.tmp-*`、`node_modules`。
6. 提交前跑 `smoke.sh`，红的不要提交。
7. 中文回复；命令、日志、标识符保持原文。

## 六、必须知道的坑（都已踩过）

| 坑 | 现象 | 解法 |
| --- | --- | --- |
| PowerShell 读中文 `.ps1` | 报 `Unexpected token`、中文乱码 | 文件必须存成 **UTF-8 带 BOM** |
| `Copy-Item -Destination` 覆盖目录 | 变成 `mods/mods` 嵌套，三个 mod 全找不到 | 拷内容：`Join-Path $source '*'` |
| `minetest.sound_play(..., true)` | 第三个参数 ephemeral 让返回值恒为 `nil`，导致"每帧重启配乐"（实测 3025 次/50 秒） | 不看句柄，按时间记账 |
| `--go` + 自定义主菜单 | 会绕过世界、自动新建「新的世界」 | 先把 `minetest.conf` 里 `main_menu_script` 注释掉 |
| `mcl_mobs.spawn` | 已弃用，日志刷 ERROR | 用 `core.add_entity(pos, "mc_mobs:bee")` |
| 无玩家时生物消失 | 实体 4 秒后 `pos=nil` | 这是 mcl_mobs 的正常 despawn，不是 bug；实机验证 |
| `mcl_poplar_poplar_shelf.png` 缺失 | 进世界左上角红字 | Mineclonia 自身资源缺项，我们已在 HUD 材质包补占位图 |
| 上游媒体许可 | Pixel Perfection 是 CC BY-SA 4.0 | 不得重新授权；新增贴图走 CC0 并单独声明 |
