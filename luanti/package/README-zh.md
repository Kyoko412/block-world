# 方块世界（Luanti 版 v0.2.1）

解压后双击 **Start.cmd**，在「启动游戏」里选世界 **blockworld**，点开始。

- 首次进入会自动生成地形，可能需要十几秒。
- 键位：WASD 移动、空格跳、Shift 潜行、Ctrl 疾跑、E 背包、Q 丢弃。
- 声音：脚步/挖掘/破坏/放置是我们的音效；进世界 14—28 秒后开始放配乐（白天/夜晚/洞穴会换）。
- 试玩蜜蜂：聊天框输入 `/bee`。
- 存档在 `worlds/方块世界`，退出后可直接备份整个 `worlds` 目录。

这是早期版本：光影与调色尚未调优，生物只补了蜜蜂原型，战斗与进食仍是上游音效。
