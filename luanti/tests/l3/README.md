# L3 验收地图

给真人 15 分钟跑一遍的交互测试。进入世界后自动生成一座平台：
12 个编号站台（羊毛色块标记）、一个水池、一段矿车轨道、一只僵尸和一只骷髅。

## 用法

```bash
bash luanti/scripts/make-l3-world.sh     # 创建/重建世界 worlds/L3-test
```

启动游戏 → 选择世界 **L3-test** → 进入后：

- `/l3` —— 打印清单与每个站台的坐标
- `/l3kit N` —— 领取第 N 个站台需要的道具（工具、护甲、药水、矿车轨等）

## 站台

| # | 站台 | 验什么 |
| --- | --- | --- |
| 1 | 合成/熔炼 | 工作台做木镐；熔炉把铁矿烧成铁锭 |
| 2 | 进食 | 饥饿条下降、回血生效 |
| 3 | 装备 | 护甲条出现；剑/盾/弓可用 |
| 4 | 酿造 | 水瓶 + 地狱疣 → 粗制药水 |
| 5 | 附魔 | 附魔台消耗青金石并出附魔 |
| 6 | 交易 | 右键村民打开交易并成交 |
| 7 | 钓鱼 | 甩竿入水，浮标下沉时能钓上东西 |
| 8 | 床 | 夜晚右键床跳过夜晚并设重生点 |
| 9 | 船/矿车 | 船下水划动；矿车沿轨移动 |
| 10 | 战斗 | 僵尸/骷髅追打，受击有反馈、死亡有掉落 |
| 11 | 红石 | 拉杆点亮红石灯（可选） |
| 12 | 退出重进 | 世界正常加载、背包保留 |

## 无头建图（CI/自测）

```bash
printf 'l3_autobuild = true\n' > /tmp/l3.conf
bin/luanti.exe --server --config /tmp/l3.conf --world worlds/L3-test --port 39999
# 日志应出现：[l3] platform built stations=12 / autobuild done
```
