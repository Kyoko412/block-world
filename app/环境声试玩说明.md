# 环境声试玩：自然、温暖的探索感

运行「方块世界.exe」。世界列表中有 **环境试听-白天林地 / 夜晚 / 雨天 / 洞穴 / 水下 / 雪天-20261111** 六个预置场景，均为不刷怪的创造模式，可以安心停留试听。

本试玩包首次默认关闭背景音乐，方便听清环境；已有设置会保留。**音效滑条控制环境声**，关闭背景音乐不应使世界静音。

## 建议试听

1. **白天林地**：轻风、树叶与偶尔的鸟鸣，中间应有安静空隙。走动几步，对比环境是否盖住脚步。
2. **夜晚**：柔和的实录虫鸣，保留录音里的自然停顿，不应像重复的电子哨音。
3. **雨天**：出生点左前方是木屋，绕到朝向出生点的门口进入。屋内雨声应更远、更闷、更轻，出屋后平滑恢复。
4. **洞穴**：已经站在地下小石室里，只有低声空气与真实滴水，不加持续低频轰鸣或进洞挖石声。
5. **水下**：已在右侧水池底部。按住空格上浮，头部出水后应恢复室外氛围；创造模式不会溺死。
6. **雪天**：轻而安静的风，不应响起持续雨声。
7. **暂停与音量**：Esc 暂停后环境声应淡出；恢复后回来。音效滑条拉到零后应安静，重新调高后恢复；背景音乐开关独立。

每个环境循环为 8—32 秒，建议在喜欢的场景多待一会儿，留意循环处是否突变，以及来回进屋、出水后是否叠得越来越响。

「试听」目录有五段各 **8 秒** 的短对照和 **40 秒** 合集，依次为白天林地、夜晚、雨天、洞穴、水下，按游戏默认音量制作。短对照开头与结尾做了淡化，完整循环在游戏里听。
