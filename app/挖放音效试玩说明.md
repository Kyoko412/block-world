# 挖放音效试玩（挖掘与放置）

打开游戏后选择世界「**挖放试听-20261110**」。这是一个安静的生存模式试玩场地，不刷怪；背包已经放好木镐、木斧、木铲和四种方块，血与饱食度都是满的。

## 场地

出生点身后（正前方是 -Z）有一排材质墙，从左到右：

| 站位 | 材质 | 墙里是什么 |
| --- | --- | --- |
| 最左 | 土 | 泥土 + 草方块 |
| 第二个 | 石 | 石头 + 圆石 + 深板岩 |
| 第三个 | 木 | 橡木原木 + 桦木原木 + 木板 |
| 第四个 | 沙砾 | 沙子 + 砂砾 |
| 最右 | 草叶 | 树叶 |

出生点前方是一圈木板边框围起来的空地，用来试放置。

## 怎么试

1. 选中木镐，站到石墙前**按住左键别松**：应当听到连续的落点，每一下不是同一条录音，力度稳定不忽大忽小；挖到最后一格时收尾的破坏声只响一次。
2. 对着土墙（拿木铲或徒手）、木墙（木斧）、沙砾墙（木铲）、树叶（徒手）各按住一次，比较五种材质的敲击：土最闷、石偏硬但不应扎耳、木有木头的空腔、沙砾是连续的沙沙摩擦、树叶是干脆的碎响。
3. 故意在墙前**按下又立刻松开**：敲击要当场停，不能松手后还在响。
4. 挖到一半换到旁边的方块再按住：应当从新方块的第一下开始，不会接着上一块的节奏补完。
5. 站到中间空地，用快捷栏里的泥土 / 石头 / 木板 / 沙子各放几块：每次放置只有一下落定声，土闷、石硬、木实；**放不进去的位置（例如叠在同一格）不应该响成功声**。
6. 挖掉墙脚的一块，再在同一位置放回去，听「破坏 → 放置」两次动作是否分得清。

`试听/` 文件夹里有每组 3.7 秒的短对照（四下敲击 → 破坏 → 两下放置），以及五组连播的 18 秒合集，可以直接和游戏里的手感对比。

## 本轮按你的反馈调整过

- 石头：收低了高频截止并补了一层低频身体，尖、刺的感觉应该轻了。
- 沙子（含砂砾）：在撞击下面叠了真正切出来的沙粒颗粒层，应该是连续的「沙沙」而不是一下闷响。
- 树叶（游戏里和草方块共用「草叶」这一路）：改成宽带碎响，音量也提了一档，不再糊在石头声里。

## 请留意

- 五种材质是否一听就能分开；石头会不会太尖、土会不会太闷。
- 连续敲同一格十几下是否烦、是否像同一条采样在循环。
- 破坏声和敲击该不该更不一样；放置是否太响、有没有和脚步声打架。
- 整体音量可用设置里的音效音量调整。

## 已知限制

- 生存模式下饱食度会随挖掘缓慢下降；这是正常消耗，不是音效问题。
- 这一包只做挖掘、破坏、放置；战斗、进食、环境声和配乐还没动，仍沿用旧声音。
